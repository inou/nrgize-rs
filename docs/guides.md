# Guides

These guides show how to do one job with `nrg`, each with a small example you can copy.

- [Writing scripts](authoring.md): how an `Energize.rhai` file is laid out and how to run it.
- [Deploying containers](deploy.md): roll out a Docker image to one or more hosts without downtime.
- [Directory releases](directory-releases.md): deploy a folder, binary or tarball without containers, and roll back instantly.
- [Secrets](secrets.md): keep passwords and tokens out of your scripts.
- [Dry run](dry-run.md): see what a deploy would do before it does it.
- [Testing a deploy](rehearsal.md): find problems before a live deploy changes your servers.
- [Recipes](examples.md): short, ready-made scripts for common setups.
